001_README.md
SAUGC OS — Sistema de Anúncios UGC com IA
Versão 1.0
VISÃO GERAL
O SAUGC OS é uma plataforma SaaS criada para centralizar e automatizar a criação de anúncios no formato UGC (User Generated Content) utilizando Inteligência Artificial.
O sistema transforma o processo tradicional de criação de anúncios em um fluxo organizado, repetível e escalável.
PROBLEMA QUE O SAUGC RESOLVE
Atualmente, empresas e criadores enfrentam dificuldades para:
criar anúncios constantemente;
desenvolver boas copies;
criar roteiros UGC;
gerar prompts eficientes para IA;
organizar campanhas;
armazenar criativos;
manter histórico de produção.
O SAUGC OS resolve isso criando um ambiente único de produção.
OBJETIVO DO SISTEMA
Criar uma plataforma onde um usuário consiga:
Cadastrar clientes.
Criar campanhas.
