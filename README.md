# ⚡ AnuncIA

**O sistema operacional da produção de anúncios UGC com IA.**

Clientes, campanhas, briefings, produção de comerciais, Mídias, biblioteca,
prompts, IA Studio e funil de vendas — organizados num painel único, premium
e rápido. Fim do caos de planilhas, WhatsApp e pastas soltas.

🌐 **Acesse ao vivo:** https://anuncia-three.vercel.app

---

## 💼 Por que existe

- **Visão de dono em 5 segundos:** MRR, conversões, ROI e funil na primeira tela
- **Padronização = escala:** briefings, roteiros e biblioteca no mesmo padrão, sempre
- **IA como copiloto:** agentes de copy e roteiros integrados ao fluxo
- **Funil que não esfria:** CRM visual do primeiro contato ao contrato fechado
- **Kanban de produção UGC:** cada anúncio sabe exatamente em que etapa está

## 🧭 Módulos (11)

| Módulo | O que faz |
|---|---|
| Dashboard | KPIs, receita, performance por canal, atividades |
| Clientes | Base cadastral com busca, filtros e tiers |
| Campanhas | Gestão por plataforma (Meta, Google, TikTok) |
| Briefings | Pedidos de produção com creators |
| Comerciais | Kanban UGC: Rascunho → Produção → Revisão → Aprovado |
| CRM | Funil de vendas com pipeline ponderado |
| Mídias | Galeria de vídeos, hooks, B-roll e fotos |
| Biblioteca | Templates, hooks de copy e guias |
| Prompts | Cofre de prompts com variáveis `{chave}` |
| IA Studio | 5 agentes × 6 modelos (GPT-4o, Claude, Gemini…) |
| Configurações | Workspaces, equipe, plano e integrações |

## 🛠️ Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 ·
shadcn-compatible · Lucide · Vercel · **Supabase** (próxima fase)

## ▶️ Rodando localmente
